# Wondervision TV

A responsive, image-backed retro television experience built with Next.js and React. The supplied television artwork acts as the frame while live React content is positioned and clipped inside the curved screen.

## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize the screen

Edit `app/page.tsx` to replace the demo broadcast with video, navigation, or any other React interface. Screen placement and CRT effects live in `app/globals.css`.

## Production build

```bash
pnpm build
pnpm start
```
